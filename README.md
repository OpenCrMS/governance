# OpenCrMS Governance

This repository holds the governance documents for **OpenCrMS**, an open source
credential management system with a focus on using the capabilities of the
[DIDComm](https://didcomm.org/) protocols for secure, private, and interoperable
exchange of verifiable credentials.

OpenCrMS is a project of [LF Decentralized Trust (LFDT)](https://www.lfdecentralizedtrust.org/)
and is run under the Maintainer Council governance model.

## Governance Documents

| Document | Purpose |
| -------- | ------- |
| [GOVERNANCE.md](./GOVERNANCE.md) | How the project is run: values, the Maintainer Council, how maintainers are added and removed, meetings, voting, and how this charter is amended. |
| [MAINTAINERS.md](./MAINTAINERS.md) | The current and emeritus maintainers, with their affiliations. |
| [CONTRIBUTING.md](./CONTRIBUTING.md) | How to contribute, including the pull request process and DCO sign-off requirement. |
| [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) | The standards of behavior we hold ourselves to, following the LFDT Code of Conduct. |
| [SECURITY.md](./SECURITY.md) | How to report a vulnerability and how the Security Response Team handles it. |
| [ADOPTERS.md](./ADOPTERS.md) | Organizations using OpenCrMS. |
| [CODEOWNERS](./CODEOWNERS) | Default reviewers for changes in this repository. |

## Getting Involved

[contributing guide](./CONTRIBUTING.md). To become a maintainer, see the
[maintainer lifecycle in GOVERNANCE.md](./GOVERNANCE.md#becoming-a-maintainer).
