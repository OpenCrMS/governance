# Adopters of OpenCrMS

This file lists organizations that are using OpenCrMS in some capacity. It provides the community, the LF Decentralized Trust Technical Advisory Council (TAC), and prospective adopters with a view of the project's adoption. Projects advancing through the LFDT project lifecycle are expected to maintain this file as part of their [annual review](https://lf-decentralized-trust.github.io/governance/governing-documents/project-annual-review/).

An adopter is any organization using the project in production, development, or evaluation, whether internally or as part of a product or service they provide.

## Adopter types

Adopters may fall into one or more of the following categories:

| Type | Description |
| ---- | ----------- |
| LFDT Member | Organizations that are [LF Decentralized Trust members](https://www.lfdecentralizedtrust.org/join) and use the project internally |
| End-User Organization | Organizations (not LFDT members) that use the project internally or build upon it but do not sell it externally as a service |
| Service Provider | Organizations that repackage the project as a core component of a service offering (cloud providers, SaaS, managed services) |
| Project | Open source projects that integrate with or depend on this project |
| Consultancy | Organizations that assist others in developing solutions using this project |

Service Provider customers are considered transitive adopters and should not be listed individually.
